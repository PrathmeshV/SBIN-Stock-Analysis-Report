#  SBIN Stock Analysis

##  Project Overview

This repository contains a comprehensive analysis of the historical stock performance of **State Bank of India (SBIN)**. Through techniques such as data cleaning, feature engineering, trend identification, and time-series forecasting, this project offers actionable insights for investors and analysts to make informed, data-driven decisions.

---

##  Objectives

- **Collect & Clean Data**: Retrieve and prepare historical stock data (daily open, high, low, close, volume).
- **Feature Engineering**: Derive technical indicators like moving averages, RSI, and MACD.
- **Trend Analysis**: Identify trends, cycles, and volatility patterns in SBIN stock.
- **Forecasting**: Apply time-series models (ARIMA, Prophet, LSTM) to project future price movements.
- **Decision Support**: Evaluate models and derive insights to guide investment strategies.
